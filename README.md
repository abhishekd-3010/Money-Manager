## ✨ Overview

**Money Manager** is a full-stack web application designed to make personal expense management simple and organized.

It allows users to record and manage their expenses through an intuitive interface while following a separate **frontend + backend architecture**.

The project focuses on clean UI, structured application logic, API communication, and persistent data management.

---

## 🚀 Features

- 💰 **Expense Management** — Add and manage daily expenses
- ✏️ **Edit Expenses** — Update existing expense records
- 🗑️ **Delete Expenses** — Remove unwanted transactions
- 📊 **Expense Tracking** — Keep track of spending activity
- 🗂️ **Organized Records** — Manage financial information efficiently
- 🔗 **API Integration** — Frontend communicates with backend services
- 📱 **Responsive Interface** — Designed for a smooth user experience
- ⚡ **Full-Stack Architecture** — Separate frontend and backend applications
